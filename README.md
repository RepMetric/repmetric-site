# RepMetric support site

Static support and privacy pages for GitHub Pages.

## Publish

1. Create a public GitHub repository named `repmetric-site` under the `Repmetric` account.
2. Upload the contents of this directory to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. After deployment, visit `https://repmetric.github.io/repmetric-site/`.

Use these App Store Connect fields:

- Support URL: `https://repmetric.github.io/repmetric-site/`
- Privacy Policy URL: `https://repmetric.github.io/repmetric-site/privacy.html`
